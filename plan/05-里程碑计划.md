## 诚实口径（贯穿全表，先定死）

本项目**当前无远端**（`git remote -v` 为空）。因此：

- 本计划所有涉及 CI 的 DoD 项一律写 **"本地等价校验（未接远端，CI 待首推验证）"**——**不写"CI 绿"**（未推送 = 未跑 CI，写了就是没发生过的事）；
- "本地等价校验"**不是一句话而是一组可指认的替代证据**：双解释器全量 pytest / 生成器 `--check` 位级一致 / 门禁 `--selftest` 阳性对照 / 基准四套件 / 冻结态验收；
- **不可本机实跑的通路显式标注"待首推验证"**（如 CI 的 ubuntu 矩阵、cp1252 环境差异）；
- M6 首推后据实补记真实 run id，**历史文档保留原措辞、补记是追加事实而非回填美化**。

## 每个里程碑的固定收尾顺序（硬约束，不得裁量）

```
DoD 验证 → plan/00·05·06 状态回写 → 写 plan/HANDOFF-M<next>.md → commit →（有远端则 push 等 CI 绿）
```

**"HANDOFF 已落盘"与"测试全绿"同级**——下个对话零上下文，K 编号/环境坑/证据位置只存在于当下对话，漏一条续接就断一节。HANDOFF 六节齐：当前进度+证据 / 下一棒待办 / 既定口径 K 清单 / 本机环境坑（只写实测过的）/ DoD 逐项 checklist / 关键命令速查。**库内一律写相对路径**（`plan/HANDOFF-Mx.md`），绝对路径只出现在用户侧启动命令里。

## M1–M6 的关键风险与预算（提前记，别等踩了才发现）

| 里程碑 | 已知风险 | 预算处置 |
|---|---|---|
| M1 | 官方快照改版/不可得 | 基准日复测；两渠道查不到即落"待核对"继续推进，不停摆 |
| M1 | 条文切分错位（交叉引用劫持） | 只认行首条号（实测序列无重复即证）；回读原文逐字校验 |
| M3 | 适用域写错（拿不适用条款指责用户） | 反向样例必红；`applies_if` 逐条挂原文限制 |
| M4 | 真值库与引擎同源 → 探活永绿 | 期望锚定冻结真值库 + 生成器独立朴素 oracle |
| M4 | 探活只打函数层（永绿门） | 探活断言 `run_benchmarks` 真返回非 0 |
| M6 | 首推 CI 诊断轮 | 预算"至少一轮诊断"；三件前置（编码护栏 + eol=lf + dev extras 齐）可消解大部分 |
| M6 | 判据锚 git 元数据（CI 浅克隆翻转） | 判据一律落**仓库内文件**（如 `plan/RELEASE-M6.md` 是否存在），不落 `git tag -l` |
| M6 | 干净环境暴露"本机碰巧装过" | 新目录 clone + 全新 venv 按 README 逐条跑；每处暴露加回归测试 |
