## 五、边界红线（贯穿全程）

1. 不做法律意见、不替代官方审查，报告强制附免责声明；
2. 不做药品推荐、不生成推广内容；
3. 纯本地处理，不上传用户文案（三层可核验证据见 `plan/03` §2.3）；
4. 品牌隔离：所有文档不提及任何姊妹项目，词表互不引用；**计划期措辞用方向级描述，领域具体名词不落库**；
5. 数值口径一处定义（`data/README.md` §五），不写漂移硬数字；**计数/哈希类随动作变化的量一律写"规则 + 快照点"，不写裸绝对值**。
