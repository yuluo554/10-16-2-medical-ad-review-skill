## 五、边界红线（贯穿全程）

1. 不做法律意见、不替代官方审查，报告强制附免责声明；
2. 不做药品推荐、不生成推广内容；
3. 纯本地处理，不上传用户文案；
4. 品牌隔离：所有文档不提及任何姊妹项目，词表互不引用；
5. 数值口径一处定义（data/README），不写漂移硬数字。
