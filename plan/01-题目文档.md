## 一、介绍

医疗、医美、药品、医疗器械、保健食品属于法定"发布前须经审查"的广告品类（《广告法》§46），且《广告法》§16/§18、《医疗广告管理办法》§7 对其内容划定了明确禁止情形。违规发布的代价是罚款、停业整顿乃至吊销执照——对医疗机构、医美机构、代运营公司与 MCN 法务而言，"发布前自查"是刚需。

本 Skill 的定位是**预审式体检工具**，不是法律意见：

1. **品类判定**：判断一段推广内容是否构成医疗/药品/器械/保健食品广告（含"以健康养生知识形式变相发布"的情形）；
2. **禁止情形核查**：对照《医疗广告管理办法》§7 八类禁止情形与《广告法》§16/§18 逐条做确定性清单核验；
3. **分级报告**：输出 BLOCK / WARN / OK 三级结论，每条命中附条款号锚点与法条原文引用。

所有规则来自**冻结的一手法条文本**（禁止情形清单、可发布内容白名单、须审查品类判定），LLM 只承担品类关键词识别与语境判断，不自行发明规则、不拍脑袋下结论。

**品牌隔离声明**：本 Skill 聚焦医疗健康类广告的事前审查（品类判定 + 禁止情形 + 审查要求），是独立细分方向，与任何通用广告文案类工具互不引用、互不依赖。

## 二、任务要求（首期模块）

### 模块 1：SKILL.md 主入口 + 内容输入

- **输入**：待审查的推广文案（单条或多条），可选元信息（发布渠道、主体类型：医疗机构/医美机构/药品厂商/普通账号）。
- **输出**：进入审查流水线的标准化内容对象（原文 + 元信息 + 唯一 ID）。
- **确定性纪律**：SKILL.md 中明确"LLM 不直接给 BLOCK/WARN 结论"，结论只能由模块 3 的确定性核查规则产出；输入文案只做本地处理，不外发。

### 模块 2：品类判定器

- **输入**：标准化内容对象。
- **输出**：品类判定结果——`医疗广告 / 药品广告 / 医疗器械广告 / 保健食品广告 / 非涉医内容`，附判定依据（命中的规则行 + 条款锚点）。
- **实现**：规则表驱动——品类关键词表 + 场景判定规则（如"以健康养生知识形式变相发布医疗广告"对应《互联网广告管理办法》§8 情形）。
- **确定性纪律**：判定规则逐条挂法条原文，未挂原文核对不得落库/生效；LLM 仅负责语境补充（如识别"变相发布"的隐性话术），LLM 输出仅作提示，不改变规则表结论。

### 模块 3：禁止情形核查

- **输入**：品类判定结果 + 文案。
- **输出**：命中的禁止情形清单，每条含：条款号锚点（如《医疗广告管理办法》§7 第 X 项、《广告法》§16 第 X 款）、法条原文引用、命中证据（文案原文片段）。
- **实现**：确定性清单核验——对照《医疗广告管理办法》§7 八类禁止情形逐条 + 《广告法》§16（医疗/药品/器械）/§18（保健食品）逐款 + 《医疗广告管理办法》§6 可发布内容白名单（超出白名单 7 项内容的告警）。
- **确定性纪律**：全部核查项必须能在冻结的 references 法条文本中找到原文出处；法条文本更新须走版本化流程（记录基准日），未挂原文核对不得落库/生效。

### 模块 4：分级报告

- **输入**：核查清单。
- **输出**：BLOCK / WARN / OK 三级报告。分级口径（一处定义，全文引用）：
  - **BLOCK**：命中任一确定性禁止情形条款（《医疗广告管理办法》§7 任一项、《广告法》§16/§18 任一款、《互联网广告管理办法》§7 须审查品类未附审查证明情形/§8 变相发布情形）；
  - **WARN**：命中白名单外但非明确禁止的表述、语境存疑待人工复核项；
  - **OK**：未命中任何规则。
  - 每条结论附条款号锚点 + 法条原文引用；报告附免责声明（辅助自查，不构成法律意见，不替代官方审查）。
- **确定性纪律**：分级映射表版本化冻结；报告生成脚本不做任何"自由裁量"。

### 模块 5：真值基准

- **输入**：合成医疗/医美广告样例集（假机构名白名单，如"XX医疗美容门诊部（虚构）"）。
- **输出**：每个样例植入真值标签（应 BLOCK / 应 WARN / 应 OK），断言分级精确匹配。
- **确定性纪律**：真值标签须逐条挂法条依据（哪个条款支撑该标签），未挂原文核对不得落库/生效；不引用真实机构违规案例。

### 扩展项（不在首期范围内）

- 医美专项：接入《医疗美容广告执法指南》规则包（⬜ 待 M1 落地一手直连源后评估，未定位到直连源前不进入首期）；
- 审查证明流程指引（《广告法》§46 事前审查要求的说明页，仅指引不代办）；
- 词表扩展机制（与任何通用极限词方向互不引用）。

## 六、边界与非目标

1. **不做法律意见、不替代官方审查**：输出仅为辅助自查参考，报告强制附免责声明；这是免责红线。
2. **不做药品推荐**：不评价任何具体药品/器械/疗法的有效性，不生成任何推广内容。
3. **隐私红线**：纯本地运行，不上传用户文案到任何外部服务。
4. **品牌隔离**：独立成题，所有文档不提及任何姊妹项目/通用极限词方向，词表互不引用。
5. **首期范围限定**：医美专项指南包（⬜ 源未落地）列为扩展项；不承诺覆盖执法案例库。
